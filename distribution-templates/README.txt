========================================
  Excel Unlocker 配布パッケージ
========================================

このパッケージは、Docker イメージを読み込んで Excel パスワード解除ツールを起動するための配布物です。
amd64（Windows/Intel/AMD）と arm64（Apple Silicon）向けのイメージが両方含まれており、setup が自動判定して適切なものを読み込みます。ファイルサイズはその分大きくなります。

■ 必要なソフトウェア
────────────────────────────────────
- Docker Desktop（インストール済みであること）
  ダウンロード: https://www.docker.com/products/docker-desktop

■ 初回セットアップ（最初の1回だけ）
────────────────────────────────────
1. Docker Desktop を起動してください（クジラのアイコンが表示されるまで待つ）
2. 以下のファイルをダブルクリックしてください：
   - Mac の場合: setup.command
   - Windows の場合: setup.bat
3. 「Docker イメージを読み込んでいます...」と表示されます（数分かかります）。環境に合わせて適切なイメージを自動で読み込みます。
4. 「セットアップ完了！」と表示されたら Enter キーで終了します

■ 起動方法（2回目以降）
────────────────────────────────────
1. Docker Desktop を起動してください
2. 以下のファイルをダブルクリックしてください：
   - Mac の場合: start.command
   - Windows の場合: start.bat
3. ターミナルが開き、「起動中...」と表示されます（初回は少し時間がかかります）
4. ブラウザで以下を開いてください：
   👉 http://localhost:3000
5. アプリケーションが表示されます

■ 停止方法
────────────────────────────────────
ターミナルで Ctrl+C（Mac でも可）を押してください。

■ トラブルシューティング
────────────────────────────────────
【問題】「ポートが使用中です」
【解決】他アプリが 3000 番ポートを使っている可能性があります。不要なコンテナ停止やブラウザタブを閉じて再試行してください。

【問題】Docker Desktop が起動しない
【解決】Docker Desktop を再インストールしてください。

【問題】画面が真っ白
【解決】ブラウザのキャッシュをクリアして再読み込みしてください。

■ 重要な注意事項
────────────────────────────────────
⚠️ このパッケージにはアプリの Docker イメージが含まれます。第三者に無断配布しないでください。
⚠️ インターネット接続は不要ですが、Docker Desktop は必要です。

■ 問い合わせ先
────────────────────────────────────
問題が解決しない場合は、配布元に連絡してください。
