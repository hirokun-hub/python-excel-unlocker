# ❓ Excel Unlocker よくある質問（FAQ）

## 📋 このFAQについて

Excel Unlockerを初めて使う方から寄せられる、よくある質問と回答をまとめました。問題解決の参考にしてください。

---

## 🚀 セットアップ・設定に関する質問

### Q1. セットアップにどのくらい時間がかかりますか？
**A1.** 初心者の方で約90分程度です。内訳は以下の通りです：
- 事前準備（アカウント作成）: 20分
- Google設定: 15分
- AWS設定: 20分
- Vercel設定: 10分
- GitHub設定: 15分
- 動作確認: 10分

### Q2. 技術的な知識がなくても設定できますか？
**A2.** はい、できます。[初心者向け完全セットアップガイド](beginner-complete-setup-guide.md)は技術的な前提知識を一切必要とせず、画面の指示に従って進めるだけで完了します。

### Q3. 設定でお金はかかりますか？
**A3.** 基本的には無料ですが、一部サービスで少額の費用が発生する可能性があります：
- **Google**: 無料
- **Vercel**: 無料プラン内で利用可能
- **GitHub**: 無料プラン内で利用可能
- **AWS**: 月額100円程度（軽い利用の場合、無料利用枠内なら0円）

### Q4. 会社のアカウントを使っても大丈夫ですか？
**A4.** はい、推奨します。特にGoogleアカウントは会社のものを使用することで、社内でのアクセス管理が容易になります。

### Q5. 設定を間違えた場合はどうすればいいですか？
**A5.** 設定は何度でもやり直せます。[トラブルシューティング診断フローチャート](troubleshooting-flowchart.md)を参照して、該当する設定を修正してください。

## 🔐 認証・ログインに関する質問

### Q6. ログインできません。どうすればいいですか？
**A6.** 以下を順番に確認してください：
1. **テストユーザー登録**: Google Cloud ConsoleのOAuth同意画面でテストユーザーに追加されているか
2. **正しいアカウント**: 登録したGoogleアカウントでログインしているか
3. **ブラウザ**: 別のブラウザで試してみる
4. **キャッシュクリア**: ブラウザのキャッシュをクリア（Ctrl+F5）

### Q7. 「redirect_uri_mismatch」エラーが出ます
**A7.** リダイレクトURIが正しく設定されていません：
1. Google Cloud Console → APIとサービス → 認証情報
2. OAuth クライアントIDを編集
3. 承認済みのリダイレクトURIに以下を追加：
   - `https://your-domain.com/api/auth/callback/google`
   - `https://*.vercel.app/api/auth/callback/google`

### Q8. 複数のGoogleアカウントを持っていますが、どれを使えばいいですか？
**A8.** 以下の優先順位で選択してください：
1. **会社のGoogleアカウント**（推奨）
2. **個人のメインGoogleアカウント**
3. **新規作成したGoogleアカウント**

### Q9. ログイン後に白い画面が表示されます
**A9.** NextAuth設定に問題がある可能性があります：
1. Vercel Dashboard → プロジェクト → Settings → Environment Variables
2. `NEXTAUTH_URL`と`NEXTAUTH_SECRET`が正しく設定されているか確認
3. 設定に問題があれば修正して再デプロイ

## 📁 ファイル処理に関する質問

### Q10. どのようなファイルが処理できますか？
**A10.** 以下の条件を満たすExcelファイルが処理できます：
- **ファイル形式**: .xlsx または .xls
- **ファイルサイズ**: 20MB以下
- **パスワード保護**: 開封パスワードが設定されているファイル
- **マクロ**: マクロ付きファイル（.xlsm）は処理できません

### Q11. ファイルアップロードでエラーが出ます
**A11.** 以下を確認してください：
1. **ファイルサイズ**: 20MB以下か確認
2. **ファイル形式**: .xlsx または .xls か確認
3. **ファイル名**: 日本語や特殊文字が含まれていないか確認
4. **ネットワーク**: インターネット接続が安定しているか確認

### Q12. パスワード解除に失敗します
**A12.** 以下を試してください：
1. **パスワード確認**: 入力したパスワードが正しいか確認
2. **複数候補**: 複数のパスワード候補を入力
3. **ファイル確認**: 元のファイルが破損していないか確認
4. **別ファイル**: 別のファイルで試してみる

### Q13. 処理にどのくらい時間がかかりますか？
**A13.** ファイルサイズによって異なります：
- **小さいファイル（1MB以下）**: 2-5秒
- **中程度のファイル（1-10MB）**: 5-15秒
- **大きいファイル（10-20MB）**: 15-30秒
- **複数ファイル**: ファイル数 × 上記時間

### Q14. 複数のファイルを同時に処理できますか？
**A14.** はい、できます。複数のファイルを選択すると、順次処理されます。進捗状況はリアルタイムで表示されます。

## 💾 Google Drive連携に関する質問

### Q15. Google Driveに保存できません
**A15.** 以下を確認してください：
1. **Drive認証**: Google Driveへのアクセス許可を与えているか
2. **Drive容量**: Google Driveに十分な容量があるか
3. **フォルダ権限**: 選択したフォルダに書き込み権限があるか
4. **再認証**: 一度ログアウトして再ログイン

### Q16. Google Driveのどのフォルダに保存されますか？
**A16.** フォルダ選択機能があります：
1. 「Google Driveに保存」をチェック
2. 「フォルダを選択」をクリック
3. 保存先フォルダを選択
4. 選択しない場合はルートフォルダに保存

### Q17. 保存されたファイル名はどうなりますか？
**A17.** 元のファイル名に「_unlocked」が追加されます：
- 元ファイル: `report.xlsx`
- 保存ファイル: `report_unlocked.xlsx`

## 🔧 トラブルシューティングに関する質問

### Q18. アプリが全く開きません
**A18.** 以下を順番に試してください：
1. **URL確認**: 正しいURLにアクセスしているか
2. **ネットワーク**: 他のWebサイトが開くか確認
3. **ブラウザ**: 別のブラウザで試す
4. **キャッシュクリア**: ブラウザキャッシュをクリア
5. **再デプロイ**: GitHub Actionsで再デプロイを実行

### Q19. エラーメッセージが英語で表示されます
**A19.** 一部のエラーメッセージは英語で表示される場合があります。主なエラーメッセージの意味：
- `Network Error`: ネットワーク接続の問題
- `Internal Server Error`: サーバー内部エラー
- `Unauthorized`: 認証エラー
- `Bad Request`: リクエストの形式エラー

### Q20. 問題が解決しない場合はどうすればいいですか？
**A20.** 以下の順序で対応してください：
1. **FAQ確認**: このFAQで類似の問題を確認
2. **診断フロー**: [トラブルシューティング診断フローチャート](troubleshooting-flowchart.md)を実行
3. **社内IT**: 社内のIT担当者に相談
4. **開発者**: 開発者に詳細を報告

## 👥 ユーザー管理に関する質問

### Q21. 新しいユーザーを追加するにはどうすればいいですか？
**A21.** 管理者が以下の手順で追加できます：
1. **Google設定**: Google Cloud ConsoleのOAuth同意画面でテストユーザーに追加
2. **AWS設定**: Lambda関数の環境変数`ALLOWED_USERS`にメールアドレスを追加
3. **動作確認**: 新しいユーザーでログインテスト

### Q22. ユーザーを削除するにはどうすればいいですか？
**A22.** 管理者が以下の手順で削除できます：
1. **AWS設定**: Lambda関数の環境変数`ALLOWED_USERS`からメールアドレスを削除
2. **Google設定**: 必要に応じてOAuth同意画面のテストユーザーからも削除

### Q23. 誰がアプリを使用できるか確認するにはどうすればいいですか？
**A23.** 以下で確認できます：
1. **AWS Management Console** → Lambda → 関数 → 環境変数 → `ALLOWED_USERS`
2. **Google Cloud Console** → OAuth同意画面 → テストユーザー

## 💰 費用・運用に関する質問

### Q24. 運用費用はどのくらいかかりますか？
**A24.** 軽い利用（月100回程度の処理）の場合：
- **AWS**: 月額50-100円程度
- **Vercel**: 無料プラン内
- **Google**: 無料
- **GitHub**: 無料プラン内
- **合計**: 月額50-100円程度

### Q25. 利用量が増えた場合の費用は？
**A25.** 利用量に応じて以下のように増加します：
- **月1000回処理**: 月額200-300円程度
- **月10000回処理**: 月額500-1000円程度
- **大量利用**: 事前に開発者に相談することを推奨

### Q26. 定期的なメンテナンスは必要ですか？
**A26.** 以下の定期メンテナンスを推奨します：
- **月次**: 動作確認、ログ確認
- **四半期**: 依存関係更新、セキュリティパッチ適用
- **年次**: 全体見直し、セキュリティ監査

## 🔒 セキュリティに関する質問

### Q27. アップロードしたファイルは安全ですか？
**A27.** はい、以下のセキュリティ対策を実施しています：
- **暗号化通信**: HTTPS通信で暗号化
- **即時削除**: 処理完了後にファイルを即座に削除
- **アクセス制御**: 招待されたユーザーのみアクセス可能
- **ログ保護**: パスワードやファイル名はログに記録されない

### Q28. パスワードは保存されますか？
**A28.** いいえ、パスワードは一切保存されません：
- **メモリ上のみ**: 処理中のメモリ上でのみ使用
- **ログ除外**: ログファイルには記録されない
- **即時削除**: 処理完了後に即座にメモリから削除

### Q29. 他の人がアップロードしたファイルを見ることはできますか？
**A29.** いいえ、できません：
- **個別処理**: 各ユーザーのファイルは個別に処理
- **一時保存**: ファイルは一時的にのみ保存
- **アクセス制御**: 他のユーザーのファイルにはアクセス不可

### Q30. iPhoneで使用できますか？
**A30.** はい、使用できます。Safari、Chrome、Edgeなどの主要ブラウザで動作します。レスポンシブデザインによりモバイル画面に最適化されています。

### Q31. Androidで使用できますか？
**A31.** はい、使用できます。Chrome、Firefox、Edgeなどの主要ブラウザで動作します。

**A32.** 以下のブラウザを推奨します：
- **PC**: Chrome、Edge、Firefox、Safari

3. **GitHub Issues**で要望を投稿（技術者向け）

### Q37. このアプリのソースコードは公開されていますか？
**A37.** 社内プロジェクトのため、一般公開はしていません。社内の開発者はGitHubリポジトリにアクセスできます。
