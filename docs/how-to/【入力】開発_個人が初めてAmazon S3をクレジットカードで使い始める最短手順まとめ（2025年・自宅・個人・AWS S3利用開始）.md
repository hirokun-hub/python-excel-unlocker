【入力】開発_個人が初めてAmazon S3をクレジットカードで使い始める最短手順まとめ（2025年・自宅・個人・AWS S3利用開始）

### 事前準備

| 必須 | 内容                           |
|------|------------------------------|
| ✅   | メールアドレス（個人用でも可）  |
| ✅   | クレジットカード（本人名義）     |
| ✅   | SMS受信できる携帯電話番号       |
| ▶️   | Google認証システムなど（MFA推奨） |

---

### 1. [[AWS]] アカウント作成手順

1. [[AWS]] サインアップページへアクセスし、メールアドレス・パスワード・アカウント名（任意）を入力
2. 画面指示に従いクレジットカード情報を登録
    - 登録時、クレジットカードの有効性チェックとして約1 USD（約150円）の一時請求→払い戻しが発生
    - 3-D Secure認証等、カード会社追加認証が求められる場合あり
3. SMSまたは音声通話で電話番号認証
4. サポートプランは「Basic（無料）」を選択
5. サインアップ完了メールが届いたら、ルートアカウントで[[AWSマネジメントコンソール]]にログイン  
   詳細手順は[[AWS公式ガイド]]参照

#### 安全対策
- ルートアカウントには必ずMFA（多要素認証）を設定
- ルート作業は最小限、以降はIAM管理者ユーザーを作成しログイン

---

### 2. 課金・コスト管理の初期設定

1. [[Billing & Cost Management]]画面に移動
2. 「Payment methods」でクレジットカードが正しく登録されているか確認し、必要なら円建ての請求書表示へ切替
3. 「Budgets」で月額予算（例：3,000円）を設定し、超過時にメール通知を設定
4. 「Cost Explorer」を有効化すると、サービスごとの料金推移がグラフで確認可能  
   詳細は[[公式ドキュメント]]参照

---

### 3. [[Amazon S3]] の料金概要

| 区分       | 無料枠（新規アカウント・12か月間）                          |
|------------|---------------------------------------------------------|
| ストレージ | 5 GB（[[S3 Standard]]）                                   |
| リクエスト | GET 20,000回/月、PUT等 2,000回/月                        |
| 転送       | データ転送料 100 GB/月                                    |

- 無料枠超過または12か月以降、東京リージョンで$0.025/GB/月（[[2025-07]]時点）で課金  
  詳細は[[公式料金表]]参照

---

### 4. 最初のバケット作成（コンソール編）

1. [[S3コンソール]] → 「Create bucket」
2. 必須項目を入力  
    - Bucket name: 全世界で一意（例: hiro-demo-202507）
    - AWS Region: Asia Pacific (Tokyo) [[ap-northeast-1]] 推奨
    - Block Public Access: 個人利用なら全てONのまま
    - Encryption: 「S3 managed key (SSE-S3)」（デフォルト）を選択
3. 「Create bucket」で完了  
   画面付き公式クイックスタートあり

---

### 5. ファイルアップロード

#### コンソールの場合

1. バケットをクリック → 「Upload」
2. ファイルをドラッグ&ドロップ → 「Upload」
3. アップロード完了後、オブジェクトのURLを確認（デフォルト非公開）

#### [[AWS CLI]]の場合

1. PCに[[AWS CLI v2]]をインストール
2. `aws configure` で Access Key / Secret、リージョン[[ap-northeast-1]]、出力フォーマットjsonを設定
3. バケット作成（未作成時）

```

aws s3 mb s3://hiro-demo-202507 --region ap-northeast-1

```

4. ファイルアップロード

```

aws s3 cp ./photo.jpg s3://hiro-demo-202507/

```

5. バケット内ファイル確認

```

aws s3 ls s3://hiro-demo-202507/

```

### 6. よく使う設定・TIPS

| シーン             | 設定・コマンド                                     | メモ                                             |
|--------------------|----------------------------------------------------|--------------------------------------------------|
| 誤削除対策         | Versioningを有効化                                 | 同じキーで上書きしても過去版が残る               |
| コスト最適化       | Lifecycleルール                                    | 30日後にStandard-IA、365日後に削除など           |
| 静的サイト公開     | 「Static website hosting」をEnabled & パブリックREAD許可 | HTTPS化には[[CloudFront]]が便利                   |
| 大量ファイル同期   | `aws s3 sync ./local s3://bucket/`                 | 差分のみ転送                                     |
| 公開用一時リンク   | Presigned URL発行                                  | 有効期限つきダウンロードリンク                   |

### 7. 次の一歩

1. [[SDK]]利用  
 - Python（[[boto3]]）、JavaScript（[[AWS SDK v3]]）などから[[S3 API]]呼び出し可
2. 自動バックアップ  
 - スマホ写真等を定期的に`aws s3 sync`でアップロードしローカル障害対策
3. 低頻度データのアーカイブ  
 - ほぼ参照しないデータは[[Glacier Instant Retrieval]]等へ自動移行で大幅コスト削減

---

### まとめ

- [[AWS]]アカウント作成 → 請求と予算の設定 → [[S3バケット]]作成 → ファイルアップロードの4ステップで[[S3]]基本利用は完了
- 新規アカウント12か月無料枠（5GB）でほぼノーコストで試用可
- 利用開始後は、バケット公開設定・MFA・予算アラートで「安全＆安心」に運用
- これで「ゼロからS3スタート」の準備は万全。ぜひ体験してみてください！
