```mermaid
---
title: "ファイル処理のデータフロー"

    participant U as 👤 ユーザー

    Note over U,S: 1. ファイルアップロード準備

    A->>L: generate-upload-url
    L->>S: 署名付きURL生成
    S-->>L: 署名付きURL
    L-->>A: upload_url + s3_key
    A-->>F: レスポンス
    
    Note over U,S: 2. ファイルアップロード
    F->>S: ファイル直接アップロード
    S-->>F: アップロード完了
    
    Note over U,S: 3. パスワード解除処理
    F->>A: 解除処理要求
    A->>L: process-file
    L->>S: 元ファイルダウンロード
    S-->>L: ファイルデータ
    L->>L: パスワード解除処理
    L->>S: 解除済みファイルアップロード
    S-->>L: アップロード完了
    L->>S: ダウンロード用URL生成
    S-->>L: 署名付きURL
    L-->>A: download_url
    A-->>F: レスポンス
    
    Note over U,S: 4. 結果表示
    F->>U: 結果表示 + ダウンロードリンク
    U->>S: ファイルダウンロード
    S-->>U: 解除済みファイル
```

### API通信のパターン

```mermaid
---
title: "API通信のパターン"
---
sequenceDiagram
    participant UI as 🎨 UIコンポーネント
    participant State as 📊 状態管理
    participant API as 🌐 API Client
    participant Backend as 🔧 バックエンド

    Note over UI,Backend: 1. ユーザーアクション
    UI->>State: ボタンクリック
    State->>State: isProcessing = true
    State->>UI: 状態更新（ローディング表示）
    
    Note over UI,Backend: 2. API呼び出し
    UI->>API: processFile()
    API->>Backend: HTTP Request
    Backend-->>API: HTTP Response
    API-->>UI: データ返却
    
    Note over UI,Backend: 3. 結果反映
    UI->>State: results = レスポンス
    State->>State: isProcessing = false
    State->>UI: 状態更新（結果表示）
    
    Note over UI,Backend: 4. エラーハンドリング
    alt エラーの場合
        API-->>UI: エラー情報
        UI->>State: error = エラー内容
        State->>UI: エラー表示
    end
```

## まとめ

### 今回のプロジェクトで学べること

1. **モダンなフロントエンド開発**
   - React/Next.jsの基本概念
   - コンポーネント指向の設計
   - 状態管理の実践

2. **API連携**
   - RESTful APIとの通信
   - 非同期処理の実装
   - エラーハンドリング

3. **認証システム**
   - OAuth2.0の実装
   - セキュアなアプリケーション設計

4. **デプロイメント**
   - 本番環境への配信
   - CI/CDの基本概念

5. **ユーザー体験**
   - レスポンシブデザイン
   - パフォーマンス最適化
   - アクセシビリティ

このプロジェクトを通じて、現代的なWebアプリケーション開発の全体像を実践的に学ぶことができます。各段階で新しい概念を学びながら、最終的には完全に機能するWebアプリケーションを完成させることができます。
