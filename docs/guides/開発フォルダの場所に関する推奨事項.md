# 開発フォルダの場所に関する推奨事項

プログラム開発を行う際、プロジェクトフォルダをどこに置くかは、開発の快適さや安定性に大きく影響します。このドキュメントでは、なぜiCloud Driveのような同期フォルダを避けるべきかと、推奨されるフォルダ構成について解説します。

## なぜiCloud Drive上での開発は非推奨なのか？

現在、このプロジェクトはObsidianのボールト内にあり、iCloud Driveによって常にクラウドと同期されています。これはメモやドキュメントには最適な環境ですが、プログラム開発には以下の理由で適していません。

1.  **パフォーマンス問題**: `node_modules`フォルダのように、多数の小さなファイルが生成されると、iCloudの同期プロセスに大きな負荷がかかり、PC全体の動作が遅くなる原因となります。

2.  **同期の競合とエラー**: Dockerのイメージファイルや、ビルド時に生成されるキャッシュファイルはサイズが大きく、頻繁に更新されます。iCloudがこれらのファイルを同期しようとすると、ファイルのロックや競合が発生し、最悪の場合ファイルが破損する可能性があります。

3.  **不要なデータ転送**: 開発中の一時的なファイルまで全てがインターネット経由でアップロードされるため、ネットワーク帯域とiCloudストレージを無駄に消費します。

## 推奨されるフォルダ構成

開発プロジェクトは、クラウド同期の対象外であるローカルフォルダに置くのがベストプラクティスです。

**推奨の場所:**
Macの場合、ホームディレクトリ直下に開発専用のフォルダを作成することをお勧めします。

- `~/Developer`
- `~/Projects`
- `~/dev`

例えば、`~/Developer` フォルダを作成し、その中に `Excel_Password` プロジェクトを移動します。

### フォルダの移動手順

1.  **Finderを開く**: Finderを起動します。
2.  **ホームディレクトリへ移動**: メニューバーの「移動」>「ホーム」を選択するか、ショートカット `Shift + Command + H` を押します。
3.  **新しいフォルダの作成**: ホームディレクトリで右クリックし、「新規フォルダ」を選択して `Developer` という名前のフォルダを作成します。
4.  **プロジェクトの移動**: 現在の `Excel_Password` フォルダを、新しく作成した `~/Developer` フォルダにドラッグ＆ドロップで移動します。

移動が完了したら、今後は新しい場所（例: `~/Developer/Excel_Password`）で作業を続けることになります。
