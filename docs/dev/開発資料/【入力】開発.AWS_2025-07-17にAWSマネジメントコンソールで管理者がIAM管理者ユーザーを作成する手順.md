
### 目的
- [[AWS]]アカウントの日常運用を[[ルートユーザー]]ではなく[[IAM]]の管理者用ユーザーで行うことで、セキュリティを強化し、最小権限の原則を実践する。  
- [[2025-07-17]] 時点の最新コンソール画面を前提にした手順。

### 前提条件
1. ルートユーザーで[[AWSマネジメントコンソール]]へログイン済み。  
2. ルートユーザーに[[MFA]]（多要素認証）が有効化されている。  
3. [[CloudTrail]] が有効になっており操作ログを取得している。  

### ステップ1: IAMサービスを開く
1. コンソール右上の検索バーに **「IAM」** と入力し、[[IAM]] サービスを選択。  
2. 左メニューから **Users** をクリック。  

### ステップ2: 新規ユーザーの基本情報を設定
1. **Add users** ボタンを押下。  
2. **User name** に `IamAdmin` など管理者用と分かる名前を入力。  
3. **Access type** で  
   - **AWS Management Console access** をチェック  
   - 必要に応じて **Programmatic access**（[[AWS CLI]] / SDK 用）も追加  
4. **Console password** は *Autogenerated* または *Custom* を選択し、**ユーザーにパスワード変更を強制**を有効化。  

### ステップ3: 権限 (Permissions) を付与
1. **Set permissions** 画面で **Add user to group** を選択し、**Create group** をクリック。  
2. グループ名に `Administrators` などを入力。  
3. ポリシー一覧から **[[AdministratorAccess]]**（AWS 管理ポリシー）をチェックし **Create group**。  
4. 作成したグループが選択されていることを確認し **Next**。  

### ステップ4: タグを付与（任意）
- 例: `Role=Admin`, `Owner=DevTeam`, `Created=[[2025-07-17]]` など、後の運用で検索しやすい情報を付ける。  
- **Next** をクリック。  

### ステップ5: 内容を確認してユーザー作成
1. **Review** 画面で入力内容を確認。  
2. 問題なければ **Create user** をクリック。  
3. 生成された **アクセスキー ID / シークレットキー**（プログラムアクセスを選択した場合）と **初回パスワード** を安全な手段で保管し、対象ユーザーに共有。  

### ステップ6: MFA を有効化
1. 作成した `IamAdmin` ユーザーを選択し **Security credentials** タブへ。  
2. **Assign MFA device** → **Virtual MFA device** を選択。  
3. 認証アプリ（[[Authenticator]] など）でQRコードを読み取り、6桁コードを2回入力して **Assign**。  
   - *QRコードに含まれる URI（例）*:  
     `otpauth://totp/AWS%20IamAdmin:AKIA...?secret=BASE32SECRET&issuer=AWS`  

### ステップ7: 動作確認
1. ルートユーザーからログアウト。  
2. `IamAdmin` で再ログインし、  
   - [[S3]] バケット作成  
   - [[Lambda]] 関数の閲覧  
   が可能か確認。  
3. ルートユーザーは緊急時のみ使用し、日常操作を行わないことをチームに周知。  

### 補足
- **パスワード/アクセスキーのローテーション**: 90 日サイクルで実施し、次回期限を例示すると [[2025-10-15]]。  
- **[[SCP]] (Service Control Policy)** を活用して、組織単位でルートユーザーの利用制限を追加するとより安全。  
- **監査対応**: [[CloudTrail]] ログと[[AWS Config]] を組み合わせ、権限変更の記録を長期保管。
