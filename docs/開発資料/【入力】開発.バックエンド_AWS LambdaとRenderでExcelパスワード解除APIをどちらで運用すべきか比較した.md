### 1. 概要

この資料は「Excelのパスワード解除API」をPythonで個人利用目的に構築し、**AWS Lambda**と**Render**のどちらが適しているか、具体的な運用イメージや費用、応答速度などを比較検討した内容をまとめたものです。

---

### 2. 要件・背景

* Python製APIを外部公開し、個人用途で利用したい
* リクエストは不定期
* アクセスがあった時にすぐ応答（低レイテンシ）
* 処理後はサーバーを停止し、コストを抑えたい
* 主な機能：Excelファイルのパスワード解除

---

### 3. 各サービスの特徴・定量比較

#### 3.1 AWS Lambda（+API GatewayやFunction URL）

* **実行モデル**

  * イベント駆動。リクエスト時のみ環境生成、処理終了で停止
* **コールドスタート**

  * SnapStart有効時、数百ms〜1秒未満
* **無料枠・料金**

  * 月100万リクエスト＋40万GB-sec無料
  * 超過分：\$0.20/100万リクエスト＋\$0.0000167/GB-sec
* **制約・仕様**

  * 1リクエスト最大15分
  * メモリ128MB～10GB、/tmp 10GB
  * Zipデプロイ50MB、コンテナデプロイ10GB
* **ファイルアップロード上限**

  * HTTP API: 10MB / REST: 6MB（それ以上はS3で回避）
* **デプロイ方法**

  * SAM/CDK/Serverless Framework、またはDockerコンテナ
* **リージョン**

  * 東京リージョン含め世界各地
* **同時実行スケール**

  * デフォルト1000並列（申請で増加可）

#### 3.2 Render（Free/Starterプラン）

* **実行モデル**

  * Webサーバー常駐。Freeプランは15分無通信で自動スリープ
  * Starter（\$7/月）はスリープなしで常時稼働
* **コールドスタート**

  * Freeプラン起動時は25〜60秒かかる
* **無料枠・料金**

  * Free：月750稼働時間＋100GB帯域（スリープ中はカウントされない）
  * Starter：\$7/月（512MB/0.5vCPU、帯域100GBまで）
* **ファイルアップロード上限**

  * 特に制限なし（自身で設定可能）
* **デプロイ方法**

  * GitHub連携やDockerビルド、GUIで操作
* **リージョン**

  * US/EUのみ（アジア拠点は現時点でなし）
* **同時実行**

  * 1インスタンス（Free/Starter）

### 5. AWS LambdaでのExcelパスワード解除API実装例

**コンテナデプロイ例**

```Dockerfile
FROM public.ecr.aws/lambda/python:3.12
RUN pip install msoffcrypto-tool openpyxl pandas
COPY excel_password_remover.py .
COPY lambda_handler.py .
CMD ["lambda_handler.lambda_handler"]
```

**ハンドラ例（10MB未満の場合）**

```python
import base64, tempfile
import excel_password_remover as unlock

def lambda_handler(event, context):
    body = base64.b64decode(event["body"])
    with tempfile.NamedTemporaryFile(suffix=".xlsx") as f_in, \
         tempfile.NamedTemporaryFile(suffix=".xlsx") as f_out:
        f_in.write(body); f_in.flush()
        unlock.remove_password(f_in.name, f_out.name)
        f_out.seek(0)
        return {
            "statusCode": 200,
            "isBase64Encoded": True,
            "body": base64.b64encode(f_out.read()).decode()
        }
```

**10MB超ファイルはS3で対応**

* S3に一時保存→Lambdaで処理→結果もS3格納
* Lambdaは10GBまでEFS接続も可能

### 6. RenderでAPI化する場合の注意

* Freeは「起床遅延」25〜60秒発生
* 無料枠は750時間/月（1日25時間×30日。ping等で常時稼働を強制すれば無料枠消費が早くなる）
* Starterは常時稼働だが月\$7、メモリは512MB

---

### 7. 結論・推奨

* **「アクセスがあった時だけ即応、終わったらスリープ」という要件にはAWS Lambdaが最適**

  * SnapStart＋API Gatewayで即起動・即停止、ほぼゼロ課金
  * 月100万リクエスト無料、東京リージョン利用可、S3で大容量ファイルも対応
* **Renderは「起床遅延OKなAPI」や「Starter課金して常時起動」の場合に適する**

  * 無料枠や遅延の仕様を許容できる用途向き

>
> * Excel等の重いファイル処理API（パスワード解除等）

> * 瞬時のレスポンス（起床遅延無し）が必要

>
