# テスト用ファイル

統合テストで使用するテスト用ファイルの説明

## ファイル一覧

- `test-password.xlsx` - パスワード付きExcelファイル（パスワード: "test123"）
- `test-no-password.xlsx` - パスワードなしExcelファイル
- `test-corrupted.xlsx` - 破損したExcelファイル
- `test-large.xlsx` - 大きなサイズのExcelファイル（10MB程度）

## パスワード候補

テストで使用するパスワード候補：
- "test123" - 正しいパスワード
- "wrong123" - 間違ったパスワード
- "password" - 一般的なパスワード
- "" - 空パスワード
