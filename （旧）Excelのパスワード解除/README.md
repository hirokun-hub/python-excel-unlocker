# Excelファイルのパスワード解除ツール

このツールは、パスワード保護されたExcelファイルのパスワードを解除し、解除済みのファイルを保存します。

## 機能

- 共通パスワードによる一括解除
- 個別パスワードによる解除
- パスワード保護されていないファイルのコピー
- 解除済みファイルの自動保存（元ファイルと同じフォルダ内の「パスワード解除済み_YYYYMMDD」フォルダに保存）

## インストール方法

1. 必要なライブラリをインストールします：
```bash
pip install -r requirements.txt
```

## 使い方

1. パスワード保護されたExcelファイル（.xls, .xlsx, .xlsm）を、このスクリプトと同じフォルダに配置します。
2. スクリプトを実行します：
```bash
python excel_password_remover.py
```
3. 共通パスワードがある場合は入力します（ない場合はEnterキーを押します）。
4. 共通パスワードで解除できなかったファイルがある場合は、個別にパスワードを入力します。
5. 解除済みのファイルは、元ファイルと同じフォルダ内の「パスワード解除済み_YYYYMMDD」フォルダに保存されます。

## 注意事項

- パスワード入力時は、入力内容が表示されません。
- 解除できなかったファイルは、最後に一覧表示されます。
- パスワード保護されていないファイルは、そのままコピーされます。
