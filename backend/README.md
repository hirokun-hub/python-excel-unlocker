# バックエンド開発

このディレクトリには、Excelパスワード解除ツールのバックエンドアプリケーションのソースコードが含まれています。

## アーキテクチャ概要

このバックエンドは、サーバーレスアーキテクチャを採用しており、以下のAWSサービスで構成されます。

- **AWS Lambda**: パスワード解除処理を実行するメインロジックです。Pythonで実装されています。
- **Amazon S3**: ユーザーがアップロードしたExcelファイルと、パスワード解除後のファイルを保管します。
- **Amazon API Gateway**: Lambda関数を外部から呼び出すためのHTTPエンドポイントを提供します。

## 主な機能

- 指定されたExcelファイルと2つのパスワード候補を受け取ります。
- 1つ目のパスワードで解除を試み、失敗した場合は2つ目のパスワードで試行します。
- 処理結果（成功または失敗）を返します。

## セットアップとデプロイ

1.  `requirements.txt`に記載されているライブラリをインストールします。
2.  AWS SAM (Serverless Application Model) や手動で、Lambda、S3、API Gatewayのリソースをデプロイします。
